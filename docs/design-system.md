# 設計規格 — shandixme.com

這是目前使用中的設計規格。色系與版面經過多輪調整才定案，更動前請先與作者確認。

首頁的漸層刻意比其他頁深，讓白色網點更明顯。雲和網點一律 `#FFFFFF`。

### 星星

`#FFFFFF`、`#94D6BF`、`#FFE48A`、`#9AA6DC`。游標拖尾的星星加 1.5px 的 `#6C78B8` 外框，在白底上才看得見。

### 不要再用的方向

- 大面積粉紅配薰衣草紫。
- 近黑底配薰衣草紫。
- 粉紅當點綴色（已全部換成薄荷綠）。
- 偏綠的灰當大面積底色。
- 聯絡區用墨綠黑（保留深藍星空）。

## 字體

| 用途 | 字體 | 粗細 |
|---|---|---|
| 標題、大數字、品牌名 | Pixelify Sans | 600、700 |
| 內文、介面小字 | DotGothic16 | 400 |

- 內文 17px，行高 1.6。介面小字 13–15px。
- 首頁 h1 用 `clamp(44px, 7vw, 80px)`，行高 0.95。
- 區塊 h2 為 56px；視窗內的次標題 24–32px。
- **中文像素字體尚未選定。** 網站文案以英文為主；作品頁的中文段落目前用 DotGothic16 顯示（缺字時由系統字體補上）。如果之後要大量加中文，Google Fonts 上沒有合適的繁體像素字體，需要另外找（例如自行託管的字體檔）並先與作者確認。

## 元件

### 視窗

```
背景 #F1F3FB · 邊框 2px #6C78B8 · 陰影 5px 5px 0 #8D97CC · 無圓角
```

標題列：背景 `#F4B8D4`，下緣 2px 邊框，內距 `6px 8px 6px 10px`。由左至右是 14×12 的像素愛心、15px 的小寫檔名（例如 `hello.txt`、`practice`、`experience.log`）、右側三顆 16px 的控制鈕（最小化、最大化、關閉，純裝飾）。

「系統訊息」視窗的標題列改用重點色 `#F29CC0`，沒有控制鈕。

### 按鈕

- 主要：背景 `#F29CC0`，邊框 2px `#6C78B8`，陰影 `3px 3px 0 #8D97CC`，高度至少 46px，左右內距 20px。
- 次要：同上，背景 `#FFFFFF`。

### 道具格 `.slot`

正方形，白底，2px 邊框。上方是 32px 的 Pixelify Sans 編號，下方是 13px 的短標題。選中時背景變重點色，加 3px 的白色內框。

### 佔位框

`repeating-linear-gradient(45deg, #F1F3FB 0 8px, #DCE1F5 8px 16px)` 的斜線底紋，中間放 `[方括號]` 說明。放上照片後要移除底紋。

### 像素愛心

7×6 的格子：

```
.XX.XX.
XXXXXXX
XXXXXXX
.XXXXX.
..XXX..
...X...
```

### 天空網點

三個 8×8 的 `<pattern>`，各放一個 2、4、6px 的白色方塊，代表疏、中、密三種密度。雲的實心部分外面包一圈「密」網點當光暈。所有座標對齊 8px 的格線。

## 動態

| 效果 | 規格 |
|---|---|
| 星星閃爍 | 透明度 1 → 0.1 → 1，`steps(4)`，每顆週期 1.6–4 秒隨機 |
| 游標拖尾 | 每 45ms 且移動超過 14px 才產生一顆；0.75 秒內下墜 26px、縮小到 0.3、旋轉 140° 並淡出 |
| 首頁照片像素化 | 預設清晰；滑過時 清晰→2→4→8→16px 方塊，每步 70ms，移開反向。觸控裝置不啟用 |
| 開場動畫（首頁） | 深藍星空上的像素書桌與 CRT 電腦：電源燈亮 → 螢幕先出現白線再撐開（老電視開機）→ 畫面閃爍出現（天空、愛心、shandixme.exe、讀取條，主機燈閃）→ 1.1s 放大衝進螢幕 → `steps(5)` 淡出到首頁。共約 4.8s，每分頁一次 |
| 捲動 | `scroll-behavior: smooth` |

以上在 `prefers-reduced-motion: reduce` 時全部關閉。拖尾在觸控裝置上不啟用。

## 版面

- 內容最大寬度 1120px（首頁主視覺 1160px），左右內距 24px。
- 視窗之間的間距 32px。
- 道具欄：桌面一排 8 格，說明框在下方滿寬，照片 3:2（最高 70vh）。
- 作品內頁：主圖滿寬、照原比例（最高 85vh）；說明與作品資料並排；照片依內容分成數個命名視窗。兩張以上的視窗滿寬、一排兩張（張數為奇數時第一張橫跨兩欄）；只有一張的視窗最寬 560px，兩個可並排。照片都照原比例。
- 斷點：900px 以下道具欄改 4 格；720px 以下桌面圖示改橫排；560px 以下道具欄改兩欄、圖庫改一欄。其餘靠 `flex-wrap` 自然堆疊。
